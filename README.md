# VELİCES

Velice Sipariş Sevkiyat — Cızırtı Bilişim

Bu herkese açık depo yalnızca Windows kurulum ve güncelleme dosyalarını içerir. Kaynak kodlar ayrı gizli depodadır. Güncelleme için şifre veya GitHub erişim anahtarı gerekmez.

Eski sürümlerden geçiş için en son kurulum dosyasını bir kez çalıştırın. Sonraki güncellemeler uygulama içinden otomatik indirilir; kurulum ve yeniden başlatma onayınızla yapılır.
